# Fuentes y atribución

Fuentes de datos y documentación técnica consultadas el 5 de octubre de 2026
(America/Guayaquil). Los enlaces sustentan el origen de los datos y las herramientas;
no convierten el código propio de este repositorio en citas literales.

1. Bittlingmayer, A. **Amazon Reviews for Sentiment Analysis**, Kaggle, versión 7.
   https://www.kaggle.com/datasets/bittlingmayer/amazonreviews
   Metadatos de la API: versión 7; última actualización 2019-11-18; licencia Unknown.
2. Bittlingmayer, A. **Amazon Reviews Sentiment with fastText [example]**.
   https://gist.github.com/bittlingmayer/a276720c513a051737464855666eca12
   Referencia del publicador del dataset; sus métricas no son las de este proyecto.
3. Zhang, X., Zhao, J. y LeCun, Y. (2015). **Character-level Convolutional Networks
   for Text Classification**. https://arxiv.org/abs/1509.01626
   Fuente original citada para Amazon Review Polarity; el proyecto usa la
   adaptación fastText distribuida en Kaggle.
4. Pedregosa, F., et al. (2011). **Scikit-learn: Machine Learning in Python**.
   Journal of Machine Learning Research, 12, 2825–2830.
   https://www.jmlr.org/papers/v12/pedregosa11a.html
5. Scikit-learn developers. **TfidfVectorizer**.
   https://scikit-learn.org/stable/modules/generated/sklearn.feature_extraction.text.TfidfVectorizer.html
6. Scikit-learn developers. **GridSearchCV**.
   https://scikit-learn.org/stable/modules/generated/sklearn.model_selection.GridSearchCV.html
7. Scikit-learn developers. **Common pitfalls and recommended practices**.
   https://scikit-learn.org/stable/common_pitfalls.html
8. Python Software Foundation. **bz2 — Support for bzip2 compression**.
   https://docs.python.org/3/library/bz2.html

La práctica no utiliza el Multilingual Amazon Reviews Corpus de Keung et al.
Ni las cifras publicadas por otros autores ni las pruebas sintéticas se presentan
como resultados del experimento de este repositorio.
